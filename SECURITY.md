# Reportar vulnerabilidades

Se você identificar uma possível vulnerabilidade de segurança no Skybird, evite publicar detalhes exploráveis, dados de usuários ou provas de conceito perigosas numa issue pública.

Use o recurso de relatório privado de vulnerabilidades do GitHub, se estiver habilitado no repositório. Caso não esteja disponível, contacte os mantenedores por um meio privado publicado no perfil/repositório oficial e forneça apenas os detalhes necessários para reproduzir o problema.

O Skybird é um projeto experimental. Não envie senhas, cookies, tokens, dados pessoais ou perfis de navegação reais em relatórios.

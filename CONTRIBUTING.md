# Como contribuir

Obrigado por considerar uma contribuição para o Skybird. Contribuições pequenas, reproduzíveis e bem descritas são especialmente úteis.

## Antes de abrir uma issue

- Confira se o problema já foi relatado.
- Informe sistema operacional e versão do Python/PySide6 quando relevante.
- Descreva os passos para reproduzir o problema e o resultado esperado/observado.
- Remova dados pessoais, cookies, tokens e informações privadas de capturas ou logs.

## Pull requests

- Mantenha o escopo da alteração pequeno e explique o motivo.
- Adicione ou atualize testes quando alterar lógica testável.
- Execute `python -m unittest discover -s tests -v` antes de enviar.
- Não inclua `.venv/`, arquivos de build, binários gerados, caches, credenciais nem dados pessoais.
- Para alterações de interface ou empacotamento, informe em quais sistemas você realmente testou a mudança. Não declare teste em um sistema que não foi executado.

As contribuições aceitas ao código do projeto serão disponibilizadas sob a licença do projeto, GPL-3.0-or-later. Os contribuidores mantêm os direitos autorais que possuam sobre suas contribuições; não há transferência automática de titularidade. Ao enviar uma contribuição, o autor confirma que tem direito de licenciá-la nesses termos.

A licença de código não concede automaticamente permissão para usar a marca ou o logotipo Skybird. Consulte `TRADEMARKS.md`.
